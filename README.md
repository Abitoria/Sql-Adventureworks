# 📊 SQL AdventureWorks Data Analysis

## 🔍 Project Overview
This repository contains relational database queries and data analysis using SQL to extract business insights, evaluate sales performance, and answer key operational questions from the AdventureWorks database.

## 🛠️ Tools & Skills
* **SQL** (Complex joins, aggregations, subqueries, filtering, and data extraction)

## 📂 Key Analyses Included
* **Sales Performance Querying:** Examined customer ordering patterns and product-level sales metrics.
* **Aggregations & Grouping:** Used advanced SQL functions to group financial data and isolate top-performing categories.
