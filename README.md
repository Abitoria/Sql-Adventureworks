**Analyst:** Olawoyin Olufunmilayo Esther

## Problem Statement
Raw enterprise databases like AdventureWorks contain massive amounts of relational data, but businesses often struggle to extract actionable insights without structured queries. Stakeholders need to evaluate sales performance, track customer ordering patterns, and isolate top-performing product categories, but wading through unorganized tables makes manual reporting slow and unreliable.

This project addresses that gap by using advanced SQL queries, complex joins, and aggregations to transform raw relational data into clean, business ready insights.

## Tools & Skills
* **SQL** (Complex joins, aggregations, subqueries, filtering, and data extraction)

## Key Analyses Included
* **Sales Performance Querying:** Examined customer ordering patterns and product-level sales metrics to track revenue movement.
* **Aggregations & Grouping:** Used advanced SQL functions to group financial data and isolate top performing categories.
